# Contributing to M5Stick-KeySender

Thanks for your interest in contributing!

The repository is being prepared for publication of the original working firmware. Until the firmware has been added, improvements to documentation and implementation suggestions are welcome.

## Reporting issues

When opening an issue, please include:
- Your M5Stick/ESP32 board model
- Your Arduino/ESP32 core version, if applicable
- Steps to reproduce the behavior
- Expected and actual results
- Serial logs or errors with passwords, network details and tokens removed

## Pull requests

1. Fork the repository and make changes on a branch.
2. Keep changes focused and explain what they do.
3. Document hardware assumptions and dependencies.
4. Test on real hardware where possible and state what was tested.
5. Never include real Wi-Fi credentials, API keys or other private information.
